## 2. Methods: Statistics Computation

Statistics are generated by `stats_raw_fastq.py` (run from the `examples/seq2neo/` directory):

```bash
python3 stats_raw_fastq.py --fastq-out stats/fastq_stats.tsv --sample-out stats/sample_stats.tsv
```

**Pipeline:**
1. Reads `data/processed/merged.json` and selects eligible samples (status = standard or extra).
2. Pre-checks file existence for all 580 FASTQ paths; missing files are warned to stderr.
3. Runs `seqkit stats --all --tabular --threads 32` on all existing files in a single invocation.
4. Produces two TSV outputs:

| Output | Rows | Description |
|---|---|---|
| `fastq_stats.tsv` | 580 | Per-file seqkit stats (num_seqs, sum_len, min/avg/max_len, Q1/Q2/Q3, N50, Q20/Q30, AvgQual, GC%, sum_n) with sample/modality/pair metadata |
| `sample_stats.tsv` | 66 | Per-sample aggregated stats: r1/r2 standalone columns for primary pairs, extra pairs aggregated together |

**Metric computation (sample-level, per modality):**

| Metric | Formula |
|---|---|
| reads | `r1_reads` + `r2_reads` |
| bases | `r1_bases` + `r2_bases` |
| GC / Q20 / Q30 / AvgQual | `(r1 + r2) / 2` (equal weight, same read count per direction) |

**Key design decisions:**
- Primary r1 and r2 are kept as standalone columns (not averaged) to reveal R2 quality degradation.
- Extra pairs per modality are aggregated together (sum reads, weighted-average quality).
- DN never has extra pairs — `DN_extra_*` columns are always empty.
- `--max-samples N` flag available for testing on subsets.

## 7. Quality Notes & Observations

1. **R2 degradation is systematic**: Q30 drops 2.5–3.2 percentage points from R1 to R2 across all modalities. This is expected for Illumina paired-end sequencing and is handled by keeping r1/r2 as standalone columns rather than averaging.

2. **RT quality saturation**: Many RT samples report Q20=100%, Q30=100%, AvgQual=30.0. This perfect-quality signal is unusual and may reflect different base quality encoding or calibration in the RNA-seq pipeline. These samples should be treated with caution in quality-filtered analyses.

3. **Read length variation**: Samples span four read-length regimes — 50–52 bp (4 samples), 76 bp (1 sample), 100–101 bp (7 samples), and 150 bp (~55 samples). The majority of samples use 150 bp reads; shorter read lengths affect bases-per-read comparisons.

4. **Set 1 skewed toward extra**: Set 1 (Colorectal) has 9 extra vs 6 standard samples (60% extra), compared to ~45% extra in other sets. This reflects the colorectal cancer cohort having more deeply sequenced tumor samples.

5. **One sample with anomalous reads**: PRJNA298376_3971 has 1,289M DN reads (r1+r2) — ~7× the sample median (185M) — suggesting this sample may have been sequenced across multiple lanes or runs.
