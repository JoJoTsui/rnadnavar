# seq2neo — Usage Guide

## Directory layout

```
seq2neo/
├── PRJNA298376.txt                  # raw manifests (inputs, read-only)
├── PRJNA298330.txt
├── PRJNA298310.txt
├── PRJNA298330.disease.tsv          # per-patient disease from NCBI BioSample
│
├── scripts/
│   ├── lib/
│   │   ├── __init__.py
│   │   └── common.py                # shared logic: disease rules, classification, partitioning
│   ├── parse_projects_to_json.py    # step 1: parse manifests → merged JSON
│   └── run_batch_from_json.py       # step 2: run nextflow per sample
│
├── config/
│   └── runner.example.yaml          # copy → runner.yaml and fill in paths
│
├── data/processed/                  # generated by parse step
│   ├── merged.json
│   ├── set1_samples.tsv
│   ├── set2_samples.tsv
│   ├── set3_samples.tsv
│   └── set4_samples.tsv
│
├── runs/
│   ├── csv/                         # per-sample nextflow input CSVs (generated)
│   └── run_state.json               # resume state (generated)
│
└── output/                          # per-sample nextflow output dirs
    └── PRJNA298376_4060/
        └── ...
```

## Sample status

| Status     | Meaning                                                   | Eligible? |
|------------|-----------------------------------------------------------|-----------|
| standard   | Exactly 1 DN + 1 DT + 1 RT pair                          | Yes       |
| extra      | All 3 modalities present, ≥1 has >1 pair                  | Yes — first pair used |
| incomplete | Missing DN, DT, or RT entirely                            | No        |

## Partition sets

| Set  | Disease(s)                                                                    |
|------|-------------------------------------------------------------------------------|
| set1 | Colorectal cancer (strict — colon/rectal are NOT included here)               |
| set2 | Colon cancer                                                                  |
| set3 | Ampullary / Bile Duct / Cholangiocarcinoma / Esophageal / Melanoma            |
| set4 | Gastric / Lung / Pancreatic / Rectal                                          |

Sets 2–4 are disease-exclusive (each disease appears in exactly one set).
Size balance is a secondary objective.

## Step 1 — Parse manifests

```bash
python3 scripts/parse_projects_to_json.py \
  --seq2neo /t9k/mnt/WorkSpace/data/ngs/xuzhenyu/work/seq2neo
```

Outputs:
- `data/processed/merged.json` — full unified sample database
- `data/processed/set{1-4}_samples.tsv` — partition membership lists
- Validation report to stdout: status counts, set counts, disease exclusivity, incomplete list

Optional: write JSON to a custom path:
```bash
python3 scripts/parse_projects_to_json.py \
  --seq2neo /t9k/mnt/WorkSpace/data/ngs/xuzhenyu/work/seq2neo \
  --out /tmp/merged_test.json
```

## Step 3 — Dry-run (preview, no execution)

```bash
SEQ2NEO=/t9k/mnt/WorkSpace/data/ngs/xuzhenyu/work/seq2neo
CFG=$SEQ2NEO/config/runner.yaml

# All eligible samples
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --dry-run

# Set1 only (Colorectal cancer)
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --dry-run --set 1

# Set1, standard samples only
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --dry-run --set 1 --status standard

# One specific patient
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --dry-run \
    --project PRJNA298376 --patient 4060

# Filter by disease substring
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --dry-run \
    --disease "Pancreatic"
```

## Step 4 — Run

```bash
SEQ2NEO=/t9k/mnt/WorkSpace/data/ngs/xuzhenyu/work/seq2neo
CFG=$SEQ2NEO/config/runner.yaml

# Run set1 (Colorectal cancer), standard samples
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --set 1 --status standard

# Run set1 including extra samples (first pair used automatically)
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --set 1

# Run all eligible samples across all sets
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG

# Run a single patient
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG \
    --project PRJNA298376 --patient 4060

# Run set2 (Colon cancer)
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --set 2

# Override pipeline path at runtime (no need to edit runner.yaml)
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --set 3 \
    --main-nf /path/to/other/main.nf \
    --rdv-conf /path/to/other.config
```

## Resume / continue

The runner writes `runs/run_state.json` with per-sample status.
Re-running the same command is safe — finished samples are auto-skipped.

**How completion is detected (strict):**
- `output/<project>_<patient>/` must exist
- All glob patterns in `completion_artifacts` (runner.yaml) must match ≥1 file

**Resume after interruption:**
```bash
# Just re-run the same command — already-finished samples are skipped
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG --set 2
```

**Force re-run one sample (clear its state and output):**
```bash
# Remove state entry
python3 -c "
import json
p = '$SEQ2NEO/runs/run_state.json'
s = json.load(open(p))
s.pop('PRJNA298376::4060', None)
json.dump(s, open(p, 'w'), indent=2)
"
rm -rf $SEQ2NEO/output/PRJNA298376_4060
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG \
    --project PRJNA298376 --patient 4060
```

**Reset all failed samples for retry:**
```bash
python3 -c "
import json
p = '$SEQ2NEO/runs/run_state.json'
s = json.load(open(p))
for v in s.values():
    if v.get('status') == 'failed':
        v['retries'] = 0
json.dump(s, open(p, 'w'), indent=2)
"
python3 $SEQ2NEO/scripts/run_batch_from_json.py --config $CFG
```

## Integration with rnadnavar

Each sample's nextflow CSV is written to `runs/csv/<project>_<patient>.csv`
with the standard rnadnavar format:

```
patient,status,sample,lane,fastq_1,fastq_2
PRJNA298376_4060,0,PRJNA298376_4060DN,LX,/path/DN_1.fastq.gz,/path/DN_2.fastq.gz
PRJNA298376_4060,1,PRJNA298376_4060DT,LX,/path/DT_1.fastq.gz,/path/DT_2.fastq.gz
PRJNA298376_4060,2,PRJNA298376_4060RT,LX,/path/RT_1.fastq.gz,/path/RT_2.fastq.gz
```

To run a sample manually with the rnadnavar pipeline directly:
```bash
HTTPS_PROXY="http://10.233.17.241:3128" \
NXF_CONDA_CACHEDIR="/t9k/mnt/joey/nf_conda_envs" \
NXF_CONDA_USEMAMBA=true \
micromamba run -n nextflow nextflow run \
  /t9k/mnt/WorkSpace/data/ngs/xuzhenyu/pipeline/rnadnavar/main.nf \
  -c /path/to/rdv.config \
  --input $SEQ2NEO/runs/csv/PRJNA298376_4060.csv \
  --outdir $SEQ2NEO/output/PRJNA298376_4060 \
  -offline -with-conda -resume
```
