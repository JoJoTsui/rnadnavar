# Frozen refined-policy cohort preparation

This is an **opt-in, standalone candidate-label rerun**, not a full Nextflow run
or training-label release. It uses `seqc2_refined_v2+seqc2_refined_gate_v1`, matching
the [frozen benchmark archive](manuscript/frozen_native_gate_20260916/README.md).
Global workflow defaults and original three-FASTQ/hybrid workflows are unchanged.

## Scope and outputs

The 66-sample shared `sample_manifest.tsv` supplies three DNA caller VCFs, three
matched RNA **realignment** caller VCFs, and existing annotated realignment rescue.
The driver normalizes private DNA copies, runs refined DNA consensus, then the
standalone refined rescue adapter, followed by structural audits. It preserves
negative labels as well as Somatic records. No truth/target filtering selects
cohort candidates. First-round rescue is not regenerated by this cohort runner.

No mapping, variant calling, RNA realignment, Nextflow invocation, original input
index rebuilding, or source-output replacement occurs. Existing Nextflow caches
are neither required nor modified. Inputs and indexes are checksummed before and
after execution. Resume requires matching code, reference, manifest, source
hashes and output hashes, not merely present artifacts. Failed attempts are kept.

Default locations, even when launched from the development repo:

- Outputs/state: `/t9k/mnt/WorkSpace/data/ngs/xuzhenyu/pipeline/rnadnavar/examples/seq2neo/output_refined_native_v2_20260916`
- Private intermediates: `/t9k/mnt/WorkSpace/data/ngs/xuzhenyu/pipeline/nf_work/refined_native_v2_cohort`
- Per sample: `<sample>/attemptNNN/refined.vcf.gz` (DNA consensus) and
  `refined.rescue.vcf.gz` (realignment-source gated rescue), indexes, logs,
  adapter report, structural audit reports and `completion.json`.
- `candidate_manifest.tsv`: completed candidates only, including `truth_vcf`
  for downstream QC compatibility. That column name does **not** imply truth
  validation or biological approval. Per-sample `state.json` is authoritative.

The annotation contract is **inherited source annotations, not new VEP**.
The inspected cohort source schema includes gnomAD/editing evidence; CSQ is not
required and may be absent, especially on baseline-only records. Do not call
these newly VEP-annotated or approved final training VCFs. If refreshed VEP is
required, add a separately verified postprocessing stage before training release.

## Preparation and launch commands

Use either checkout after syncing code and its Python environment. Commands are
relative to its root; defaults still write to the shared locations above.

```bash
cd /t9k/mnt/WorkSpace/data/ngs/xuzhenyu/pipeline/rnadnavar
.venv/bin/python examples/seq2neo/scripts/run_refined_cohort.py
```

This performs preparation only. Optional `--plan /absolute/new-plan.json` saves a
new report without replacing an existing one. It checks count/uniqueness, source
presence/indexes/BGZF EOF, header dictionaries and native evidence schema,
sample interpretation, original indexed first-record access, source/output
separation, cgroup limits and estimated disk space. This is not full-record
validation; full parsing and checksums occur at execution. Older index timestamps
are reported and first-record access checked, not proof of full index validity.
Filesystem free-space estimates do not establish user/project quota availability.

First run the representative pilot (not launched during preparation):

```bash
.venv/bin/python examples/seq2neo/scripts/run_refined_cohort.py --pilot --execute > examples/seq2neo/refined_native_v2.pilot.log 2>&1
```

Pilot IDs: `PRJNA298330_4032`, `PRJNA298376_4278`, `PRJNA298376_4255`.
Review counts/FILTER spectrum, promotion and protected-negative behavior,
annotation coverage, structural audits, memory/runtime and source integrity.
Run report-only biological label QC; do not apply automatic label cleaning.
Only after that review, explicitly authorize the full cohort:

```bash
.venv/bin/python examples/seq2neo/scripts/run_refined_cohort.py --all --approve-pilot --execute > examples/seq2neo/refined_native_v2.cohort.log 2>&1
```

The full command refuses missing/inconsistent pilot outputs. `--approve-pilot`
acknowledges an operator's candidate-generation review, **not** biological
training-label approval. Repeating a command skips only verified successes.
Changed code/reference/manifest requires a new output namespace/config.

## Resource and release gates

The new JSON config bounds concurrency to two single-thread jobs, each with a
16 GiB address-space limit; an 8 GiB reserve is included in cgroup admission.
It does not inherit the old Nextflow 104-CPU/220-GB resource configuration.
Disk admission estimates at least 100 GiB or 12 times compressed inputs. Private
SQLite stores/intermediates are retained, ignored by Git, and need storage quota.

Before training use: complete cohort-level biological QC, review common-AF and
RNA-editing conflicts and RNA-only negatives, confirm required annotation and
sample completeness, and approve label semantics. Structural audits do not
establish biological correctness. Preserve both DNA and rescue candidates: the
HG008 evaluation did not show rescue universally improving the DNA baseline.

Preparation tests execute tiny synthetic data only. No real cohort/pilot job is
started by default; no global default integration is needed for this opt-in path.

## Recorded preparation, 2026-09-16

All **66 samples / 462 source VCFs** passed the header/schema, reference dictionary,
BGZF EOF and indexed first-record checks. All RNA panels and source rescues were
from realignment paths. No rescue header had VEP CSQ (0/66).
267 VCFs had at least one index older than the VCF; the indexed first records
matched the sequential records. This is a timestamp warning, not certification
of every indexed region. Original indexes were not modified.

Compressed sources plus indexes totalled 10,357,050,983 bytes. Estimated disk
headroom required was 124,284,611,796 bytes (about 116 GiB), and filesystem free
space passed. Local cgroup limits were 46 CPUs and 83,751,862,272 bytes (78 GiB);
the new 40 GiB total admission budget fits. Check quota and competing jobs again
at launch. Detailed local report: `.artifacts/refined_cohort_preflight_20260916_v2.json`.
The committed config/runbook, not that machine-specific report, drives execution.
