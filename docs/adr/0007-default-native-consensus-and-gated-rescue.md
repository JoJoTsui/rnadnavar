# Enable native consensus and gated rescue by default after cross-cohort validation

The pipeline will treat native-evidence SNV consensus and gated cross-modality rescue as the target default policy for DNA-only, hybrid, BAM, and FASTQ workflows, while retaining explicit opt-outs. Default-on release is contingent on validation against SEQC2 WES-LL/WES-IL/WGS-IL and an independent HG008 somatic benchmark, with DNA DeepSomatic as the required comparator, separate SNP/indel accounting, a precision-loss budget, and zero valid-input execution failures. Existing caller and alignment outputs remain reusable; cohort re-consensus reads the six existing caller VCFs and realigned-RNA VCFs, writes to a new `examples/seq2neo` output namespace, and reports incomplete inputs explicitly rather than mutating source outputs or silently substituting rescue artifacts.
